# The One-Line Cat Joke That Lands

One joke about cats (≤200 characters), setup and turn in a single line.

> My cat walked across my keyboard and typed a stronger password than I've ever chosen — then sat on the mouse so I couldn't change it.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
